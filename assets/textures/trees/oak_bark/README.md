# Jolcham Oak Bark 01 PBR channels

These matched 1K x 2K JPEG channels come from Poly Haven's
[Jolcham Oak Bark 01](https://polyhaven.com/a/jolcham_oak_bark_01), authored by
Charlotte Baglioni. Poly Haven documents the scan as one metre wide by two
metres tall and publishes it under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

The diffuse image is sRGB. The OpenGL normal and packed ambient-occlusion,
roughness, and metalness image are linear data. All channels repeat over the
same metric cylindrical UV mapping.
