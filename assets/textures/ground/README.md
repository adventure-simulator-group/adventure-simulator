# Dirt PBR channels

These matched 1K JPEG channels come from Poly Haven's
[Dirt](https://polyhaven.com/a/dirt), authored by Charlotte Baglioni. The
two-metre-wide scan is published under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

The diffuse image is sRGB; the OpenGL normal and packed
AO/roughness/metal images are linear data. The tactical terrain material maps
them at their documented 0.5-tile-per-metre scale and fades the detail before
it becomes subpixel.
