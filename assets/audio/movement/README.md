# Movement audio sources

- `footstep_*.ogg` and `impactSoft_heavy_*.ogg` are selected from Kenney's
  **Impact Sounds** pack: https://kenney.nl/assets/impact-sounds
- `wind_loop.ogg` is **wind whoosh loop** by SketchMan3:
  https://opengameart.org/content/wind-whoosh-loop
- `foliage_rustle.ogg` is **moving leaves stereo.ogg** by Augmentality
  (Brandon Morris), from **Random Sounds Samples**:
  https://opengameart.org/content/random-sounds-samples

All listed source pages publish these files under Creative Commons CC0.
