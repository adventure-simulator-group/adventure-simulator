# Rain audio sources

- `soft-ground.ogg`, `foliage.ogg`, `hard-ground.ogg`, and `water.ogg` are
  selected recordings from **Rain (loopable)** by Ylmir:
  https://opengameart.org/content/rain-loopable
- `rain-heavy.ogg` is **AMB Rain Loop 1** by Kresiek The Furry:
  https://opengameart.org/content/amb-rain-loop-1

Both source pages publish the recordings under Creative Commons CC0.
