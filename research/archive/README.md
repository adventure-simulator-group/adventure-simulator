# Archived wiki evidence

This directory preserves documentation removed from the published *Fabelgeist*
wiki during the Issue 487 greenfield cutover. It is historical evidence, not
authoritative project documentation. Do not use it to infer current behavior;
inspect the code and tests instead.

The `wiki/` directory preserves the former page topology and navigation files.

This evidence set is intentionally not a self-contained mdBook. Human-authored
pages retained in the greenfield wiki and shared assets were not duplicated, so
links in the preserved navigation snapshot may target files outside this
directory or files that are no longer part of the archived evidence set.
